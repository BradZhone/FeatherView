# 架构说明

[English](architecture.md)

FeatherView 是基于 AppKit 的 Objective-C 应用，没有第三方依赖，由 `make` 直接调用 clang 构建。设计围绕一个目标展开：**在单个原生进程中提供文件查看与简单编辑能力，并尽可能降低内存占用。** 以下各项设计取舍均由此而来。

## 源码结构

```
src/
  Support/   本地化（FTL / FTLP）、FTSplitView、FTTabDrag 与 FTTabDropView
  App/       应用入口、窗口、菜单、标签页与文档管理（ContentController）、设置、欢迎页、默认打开方式
  Editor/    文本编辑器：PieceTable 缓冲区；TextEditorView（绘制、输入、自动换行、小地图、搜索）；
             语法高亮；标签栏
  Files/     文件树、目录遍历与过滤、文件操作、类型识别、文件图标
  Search/    工作区搜索（ripgrep 或内置遍历器）、搜索面板、快速打开
  Preview/   Markdown 解析与原生渲染、HTML 预览、表格 / 树形 / Notebook 视图及其数据模型
  Viewers/   图片、SVG、PDF、十六进制、SQLite、压缩包查看器
  Terminal/  TSession（PTY 与生命周期）、VTEscape、TScreen、TerminalView 与 TerminalPanel
Resources/   各语言的 <lang>.lproj 字符串表
tests/       九个测试程序：纯 Foundation 逻辑、Markdown 解析、终端内核、编辑操作、
             真实视图、应用终端生命周期、终端输入路由、文件树与侧边栏、标签拖拽
tools/       以代码绘制的应用图标
scripts/     安装、发布打包、资源占用对比、本地化检查、Info.plist 文档类型生成
docs/        本文档与资源占用对比
```

模块之间直接引用彼此的头文件。Makefile 为每个模块添加 `-I` 参数，因此 `#import "FileKind.h"` 无需写路径。

## 设计取舍

**编辑器不使用 NSTextView。** `TextEditorView` 是自行管理滚动的 `CanvasView`，每一帧只用 CoreText 排版可见的行。文本存储在 `PieceTable` 中：原文件以内存映射方式读取而不复制，修改追加到 add buffer，并同时维护一张行首偏移表。因此打开 100 MB 的日志与打开 1 KB 的文件，内存开销几乎相同，参见[资源占用对比](benchmark.zh-Hans.md)。

**自动换行基于前缀和。** 开启换行时，`_rowStart[L]` 记录逻辑行 L 的第一个视觉行。行号与视觉行之间的换算均为二分查找；编辑时只重新测量受影响的行，再整体平移其后的数据，在 10 万行的文件中每次按键约 0.04 ms。断行规则（在空格以及 `-`、`/`、`,` 等字符之后断行；中日韩字符之间可断行；`，`、`。` 不出现在行首；续行保持原行的缩进）集中在 `rowsOf:width:` 一个函数中，由行表构建、绘制、点击定位和光标移动共用，因此显示内容与点击位置始终一致。窗口宽度变化时，以视图顶部的逻辑行为锚点重建行表，内容不会跳动。

**Markdown 原生渲染，仅 HTML 使用 WebKit。** WKWebView 会启动 GPU、WebContent、Networking 三个辅助进程（实测约 70 MB），并且这些进程会一直保留到应用退出。因此 Markdown 由 FeatherView 自带的解析器转换为 TextKit 富文本显示，只有在真正打开 `.html` 文件时才创建 WebView；不查看 HTML 的会话不会产生这部分开销。

**新预览等待实际布局。** `MarkdownPreview` 和 `PDFPreview` 保留一次性的初始定位请求，直到视图挂载且几何尺寸可用。Markdown 先建立 TextKit 布局再滚动到文档原点；PDFKit 将第一页的显示顶部转换回页面坐标，计入裁剪原点与旋转。显式锚点、源码 / 页面导航及查找结果优先生效。请求执行或被取代后，不会因调整大小或切换焦点再次执行。

**数据视图按需解析。** CSV 单元格以字节区间（`uint32` 数组）存储，而不是为每个单元格创建字符串。JSON 由自带的解析器读取，保留键的顺序和行号，以便“在源码中显示”能准确跳转。SQLite 文件以只读方式打开并分页查询。压缩包内容通过系统自带的 `bsdtar` 列出。

**对异常输入设定上限。** 文件常由工具生成或来自他处，因此每个解析器都设有上限，而不是信任输入：Markdown 的块级嵌套最多 48 层、行内嵌套最多 32 层，强调采用 cmark 的线性“openers bottom”算法匹配；JSON 和属性列表最多 200 万个节点（一个几百字节的二进制 plist 就能描述指数级大小的树）；表格最多显示 1,000 列；正则表达式在一行上超过 2 秒即放弃。`tests/markdown_tests.m` 和 `tests/tests.m` 会对这些极端情况计时。

**保存不会丢失原文件。** `save:` 先在同一文件夹写入临时文件，复制原文件的权限、扩展属性和 ACL，再重命名覆盖原文件；写入失败时原文件保持不变，内存映射的缓冲区也依然有效。有两种情况改为原地写入：存在其他硬链接的文件，以及位于只读文件夹中的可写文件；两者都仅限已读入内存的小文件。只读文件会被拒绝保存。“全部替换”一次生成新文本并替换缓冲区，撤销时再换回。

**多光标是一次修改，而不是多次。** 主光标就是编辑器的 `_anchor` / `_caret`，因此输入法、VoiceOver 和查找仍按单光标工作；其余光标保存在一个有序且互不重叠的数组中。每个命令先生成一组替换（`EditList`），由 `PieceTable applyEdits:` 一次遍历片段和行首表完成，换行表也只遍历一次并重新测量受影响的行。撤销记录以每次修改为一批，同时保存修改前后的全部光标；连续的按键会并入同一批，因此在 10,000 个光标处输入一个单词只占一个撤销步骤、共 10,000 处修改，而不是 70,000 处。由于多光标会产生大量片段，片段查找改为按片段偏移二分查找。

**终端 = PTY + 解析器 + 字符网格。** `TSession` 在伪终端上运行登录 shell；串行队列处理 I/O，主线程按有上限的块解析。`VTEscape` 通过 CSI、OSC、DEC 私有模式和跨块边界的 UTF-8 驱动 `TScreen`。网格支持延迟自动换行、备用屏幕和 5,000 行回滚。每个屏幕均初始化 ANSI 16 色与 xterm 256 色调色板；各视图按外观设置前 16 色。真彩色 RGB 黑色与默认颜色标记保持区分。调整大小时保留内容而不重排：全屏滚动区跟随新高度，显式边界会被限制并恢复；缩小时先移除底部空余空间，再将光标上方的行移入历史，增大时可将历史移回网格。

**每个终端会话跨位置复用一个视图。** `ContentController` 维护会话到唯一 `TerminalView` 的缓存，通过 `viewProvider` 提供给 `TerminalPanel`。同一个视图在编辑器标签页和面板栏之间移动，除会话的 PTY 和回滚历史外，还保留视口、选区和跟随状态。隐藏、脱离层级或过小的几何尺寸不会调整 PTY。逻辑历史锚点在输出到来时保持阅读位置；向上滚动会暂停跟随，回到底部后恢复。`TerminalView` 用 CoreText 绘制，转发按键与鼠标事件，并在光标处挂载输入法。终端内核仍为纯 Foundation 代码，因此 `build/terminal_tests` 无需 AppKit 即可驱动真实 shell。

**终端控制键优先于文本输入处理。** `TerminalView` 处理原生快捷键路由，将标准终端控制键编码后发送，普通文字再交给 `inputContext`。即使有文字选区，⌃C 也会发送中断字节；终端获得焦点时，⌃R 和 ⌃G 优先于“切换工作区”和“跳到行”的菜单快捷键。⌘ 命令仍通过菜单路由，标记文本的组字和导航仍由输入法处理。

**终端生命周期独立于界面所有权。** `TSession.liveSessions` 强引用尚未完成的会话，包括已不属于任何标签或面板的关闭中会话。记录含应用及 UID 标记，以及所有者、shell 和受跟踪作业的内核进程身份：PID、启动时间、UID、可执行文件、会话和进程组。异步孤儿回收要求记录中的所有者已确认死亡，并在发送信号前重新核对完整身份。存活或无法验证的所有者、重用的 PID 和无法验证的旧记录均不能授权发送信号；旧记录仅被移除，不按 shell 名称终止进程。PTY 描述符设置执行时关闭，启动 shell 时关闭无关的继承描述符。

终止操作可重复调用：经过验证的会话成员和后代先收到 HUP，宽限期后仍存活且通过验证的作业再收到 KILL。只有子进程已回收、PTY 到达 EOF 且缓冲输出全部解析、描述符已关闭、受跟踪作业已清理，才算完成。shell 退出本身不会丢弃最后一段输出。`shutdownAllSessionsWithTimeout:` 持续运行 run loop；超时后仍保留未完成的会话和记录。应用通过 `NSTerminateLater` 异步等待，清理完成后才回复退出请求。此恢复策略覆盖可验证的应用记录，不涵盖机器上遗留的所有 shell 进程。

**折叠的行不占行位。** 折叠沿用自动换行的行位表：被隐藏的行计为 0 行，因此绘制、点击定位和上下移动无需了解折叠即可跳过这些行；只要存在折叠，即使未开启自动换行也会使用该表。每次编辑前，每个折叠区域转换为两个偏移（首行末尾与最后一个隐藏行末尾），按其前方的编辑调整，编辑后再换算回行号；触及隐藏行的编辑会取消该折叠，此时行位表改为完整重建。

**编辑器与终端各自独立分屏。** 每个 `FTSplitView` 最多持有 3 个子视图，按项目对象身份保存归一化的手动栏宽。各区域的 `maximized` 展开标志均默认为关闭。双击标签或按 ⌃⌘M 可切换所在区域的展开状态；双击编辑器临时预览标签时仍会将其固定。开启后，展开跟随焦点，分组顺序不变；其他分组保留 180 pt 最小宽度，仅在空间不足时缩小为均分宽度。关闭展开时恢复已保存的手动栏宽权重。分隔条的点击检测优先于子视图；拖动会关闭展开并保存所选比例，随窗口缩放保留。焦点切换不会自动重新开启展开，即使目标分组已达到最小宽度。区域减少至一个或零个子视图时，展开状态重置为关闭。

每个编辑器 `PaneView` 拥有自己的标签条、查找条和活动内容。按对象身份连接的回调、`_paneActive` 和 `Doc.pane` 重编号，使查看器在切换焦点时保持挂载，移除左侧或中间栏后其余标签仍被保留。`FTTabDrag` 使用进程内令牌和主窗口鼠标拖动会话：标签条显示插入线并负责排序，栏主体显示半栏宽的分栏预览并负责分栏 / 合并；标题条和查找条不会被蓝色预览覆盖。HTML 与终端子视图不会吞掉拖动，Esc、窗口失焦和关闭窗口会安全取消。源栏为空时移除，编辑器栏位分配随会话保存。`TerminalColumnState` 独立拥有宿主视图和会话标签数组，面板从控制器取得每个会话的唯一视图。普通新建终端会追加为当前栏中的标签；3 栏上限不限制会话数量。

**侧边栏作为整体隐藏。** `AppDelegate` 将整个“文件 / 搜索”侧边栏放在外层 `NSSplitView` 中。标题栏按钮和 ⌘B 可隐藏或显示侧边栏，并在窗口可用空间内恢复原宽度。“文件树”（⇧⌘E）和工作区搜索（⇧⌘F）会显示侧边栏并选中对应标签。`FileTree` 持有文件树上方的原生**全部折叠**文字按钮；递归折叠期间抑制选择回调，避免隐藏嵌套行时重新展开文件夹或切换当前文档。已打开的文档保持完整。

**用 FSEvents 监视工作区。** `FileWatcher` 报告工作区文件夹下的变化，以半秒为单位合并，并忽略 `.git`、`node_modules` 等跳过的文件夹。文件树随后在后台队列重新读取已展开的文件夹，只有列表变化时才刷新。

**工作簿按字节区间拼接修改，而不是整体重写。** .xlsx 是由 XML 部件组成的 zip 包。`ZipArchive` 对未改动的条目连同压缩数据逐字节复制。`XLWorkbook` 在读取工作表时记录每个单元格元素的字节区间；保存时只替换被修改单元格的区间（或按顺序插入新元素），设置 `fullCalcOnLoad` 让 Excel 和 Numbers 重新计算，并移除可选的计算链。因此图表、数据透视表、宏、批注和条件格式都不会被触及。保存结果会先重新解析一遍，确认无误才替换原文件。Word 文档只做显示：由系统的 Office 转换器（Quick Look 使用的同一个）生成 HTML，在禁用脚本的网页视图中显示，因为 macOS 上没有任何转换器能在不丢失内容的情况下保存 .docx。

**图片按显示尺寸解码。** ImageIO 只解码当前缩放级别所需的像素，放大时重新解码，上限为 2400 万像素。

**不抢占默认打开方式。** `Info.plist` 中所有文档类型均使用 `LSHandlerRank None`。安装后 FeatherView 只会出现在“打开方式”菜单中，不会自行成为任何文件类型的默认应用；只有用户在“默认打开方式”面板中明确勾选时才会更改。`tests/tests.m` 会检查这一点。

**界面文字支持本地化。** 开发语言为英文，英文原文即为键：`FTL(@"Save All")`。与数量相关的文字使用 `FTLP(n, @"%lu file", @"%lu files")`，英文在数量恰好为 1 时选用单数形式。翻译存放在 `Resources/<lang>.lproj/Localizable.strings` 中，macOS 根据用户的首选语言顺序选择界面语言（`zh-Hans` 时为简体中文，其余为英文）。`scripts/l10n.py` 作为 `make test` 的一部分运行，若出现缺少翻译、键与译文的格式说明符不一致、存在未使用的翻译，或源码中在字符串表之外出现中文，测试即失败。

## 测试

```bash
make test
```

- `scripts/l10n.py`：翻译覆盖率与格式说明符一致性。
- `build/tests`：PieceTable、目录遍历与过滤、搜索参数，以及 CSV、JSON、Notebook 解析等逻辑测试。
- `build/markdown_tests`：91 个 Markdown 用例，包括元数据、强调与链接的 CommonMark 示例、极端输入的耗时上限和嵌套上限。
- `build/terminal_tests`：转义序列解析（颜色、滚动区域、备用屏幕、宽字符、UTF-8 容错）、随机字节模糊测试与限时，以及在真实 PTY 上运行 `/bin/sh`（回显、退出码、2 万行输出、终止）。
- `build/editing_tests`：多光标、行操作和输入辅助，用带光标标记的文本书写（`"a|b\nc[d|]"`）；另含多光标编辑下换行表的随机测试，以及 10,000 个光标的计时。分屏覆盖默认关闭展开、双击标签独立切换、分隔条拖动与手动栏宽恢复、焦点切换保留手动栏宽，以及已保存的编辑器栏位分配。
- `build/editor_tests`：在离屏窗口中驱动真实的编辑器、文件树、标签页、预览和各类查看器，检查行为、像素与性能，例如“10 万行文件中小地图每帧耗时低于 16 ms”“每次编辑后，增量维护的换行表与完整重建的结果一致”；还覆盖 Markdown / PDF 首次布局定位与导航优先级、切换分屏焦点或移除栏时保留查看器，以及两种语言的菜单和状态栏。
- `build/session_lifecycle_tests`：应用层终端清理，覆盖标签失去界面所有者、同时含终端标签和面板会话的窗口关闭，以及 shell 忽略 HUP 时退出应用；检查子进程回收、输出排空和全局活动会话注册表。
- `build/terminal_input_tests`：原生 AppKit 按键路由、标准控制键与导航序列、⌃R / ⌃G 菜单冲突、⌘C 选区行为和输入法提交；隔离的真实 PTY 检查准确字节、⌃C 中断、⌃D EOF 和 ⌃Z 挂起行为。
- `build/file_tree_tests`：原生文件夹与展开控件点击、递归全部折叠且不改变已打开文档和未保存修改、折叠后刷新、侧边栏隐藏 / 显示与宽度恢复、显示“文件 / 搜索”标签，以及空根目录。
- `build/tab_drag_tests`：通过真实主窗口的鼠标事件队列验证编辑器 / 终端排序、分栏、合并、面板 / 编辑器迁移、HTML 预览、取消操作、半栏预览区域和窗口布局稳定性；确认原 PTY 在移动后仍可执行命令。

`make sanitize` 用 AddressSanitizer 和 UndefinedBehaviorSanitizer 构建并运行全部九个测试程序；`make analyze` 运行 clang 静态分析器，有任何警告即失败。

测试使用独立剪贴板、可注入的回收站处理器和临时目录，不使用用户的剪贴板、废纸篓、未命名文档备份或真实设置。终端启动与孤儿回收测试必须在创建或回收会话前，将 `FEATHERVIEW_TERMINAL_PIDS_DIR` 设为隔离的绝对目录。
